使用说明

  • 支持播放本地 FLV 文件和在线 FLV 视频地址
  • 播放后顶部规格栏实时显示分辨率、帧率、码率和时长（直播流显示为“直播”）
  • 点左上角“录制”可把当前直播录成 mp4（浏览器支持时），单段满 10 分钟或 250MB 自动分段续录
  • 切到后台会立刻把当前段落盘，回到页面自动接着录新的一段；锁屏、被系统回收仍会丢
  • 录制时请保持页面在前台、屏幕常亮，切到后台或锁屏会中断
  • 视频编码要求：H.264；音频编码要求：AAC 或 MP3
  • 浏览器需支持 Media Source Extensions (MSE)，推荐 Chrome / Firefox / Edge
  • 在线播放时请确保视频服务器允许跨域访问（CORS）
  • 可通过 URL 参数直接播放：?shared=http://example.com/video.flv
