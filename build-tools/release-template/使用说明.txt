星曦向荣直播监听 · 使用说明
========================================

一、第一次使用（三步）
1. 把整个文件夹解压到硬盘上（例如 D:\直播录屏\星曦向荣），不要只把「直播监听.exe」单独拷出来。
2. 双击「直播监听.exe」。
   · 如果电脑上还没有监听用的浏览器组件，会提示是否下载（约 150MB，需要联网），点「是」自动装好。
   · 装好后程序自动启动，并自动用浏览器打开监听面板（默认 http://localhost:8005）。
   · 首次使用有 7 天试用期，不需要激活码，界面和日志会提示剩余天数。
3. 面板里的「新增监听」等操作要输入操作秘钥，秘钥就是本机的设备标识：
   双击「获取设备标识.bat」可以看到，面板上也会有提示。

二、添加要监听的直播间
· 面板中点「新增监听」，粘贴直播间 ID 或链接，选择平台，保存即可，程序会开始监听。
· 也可以把 *.room.json 文件放进 room 目录，重启程序后自动读取。

三、录像保存在哪
· 每个直播间一个文件夹，路径可以在面板里看到/修改（默认在程序目录下）。
· 录像依赖 bin\ffmpeg.exe，已经内置，不用另外装。

三之二、登录抖音 / B站（可选，但推荐）
· 不登录也能监听，只是可能拿不到昵称、粉丝数、部分清晰度等信息。
· 双击「获取抖音登录信息.bat」→ 弹出浏览器 → 用抖音 App 扫码登录 → 自动保存到 cookie\DouYin.cookie；
  双击「获取B站登录信息.bat」→ 用手机 B 站 App 扫码 → 自动保存到 cookie\Bili.txt。
· 脚本会自动在 xxxr.setting 里启用 Cookie.DouYin / Cookie.Bilibili（原文件备份为 xxxr.setting.bak），
  重启「直播监听.exe」后生效。登录过期（一般几十天）后重跑一次脚本即可。
· 第一次跑之前要先「安装监听浏览器.bat」，否则脚本会提示缺少浏览器直接退出。

四、开机自动启动（可选）
· 按 Win+R 输入 shell:startup 回车，把「直播监听.exe」的快捷方式拖进去即可。

五、怎么退出
· 推荐：面板右上角电源按钮（需输入秘钥），程序会先停监听、再退干净，不会残留 ffmpeg 进程。
· 也可以：托盘图标右键 →「退出程序」。
· 直接关窗口不会退出程序（它常驻在托盘），这是正常设计。

六、常见问题
· 双击没反应：查看 logs\launcher.log 和 logs\application.log 最后的报错。
· 提示缺少监听浏览器：双击「安装监听浏览器.bat」，等它跑完再启动。
· 端口 8005 被占用：程序会自动用 8006、8007……，实际地址看日志或托盘提示。
· 托盘里没有图标、找不到面板：程序在“没有监听在跑”时会保留一个「面板入口」图标，
  右键 →「监控界面」即可；启动时也会自动弹一次浏览器。
· 杀毒软件报警：exe 只是本机编译的启动器（用来找内置 Java 并拉起程序），
  信任/放行整个文件夹即可。
· 换电脑：试用期与设备绑定，换机重新计算试用；正式使用需要对应设备的激活文件。

七、目录说明
  直播监听.exe      双击这个启动
  jre\             内置的 Java 8 运行环境（不用另外装 Java）
  lib\             程序主体（live-monitor-record-*.jar）
  bin\             ffmpeg.exe，录制用
  room\            直播间监听文件（*.room.json）
  cookie\          平台登录 Cookie（获取抖音/B站登录信息.bat 生成）
  logs\            运行日志（排查问题看这里）
  tools\           激活工具目录（单独分发，压缩包里不含此目录）
  xxxr.setting     配置文件，改完要重启程序
  安装监听浏览器.bat / 获取抖音登录信息.bat / 获取B站登录信息.bat / 获取设备标识.bat
                   几个辅助脚本，双击运行，按提示操作

八、试用期与激活
· 试用到期后，程序仍会正常启动并提示，但不能再新增监听、重启监听或手动开录制，
  已在运行的监听不受影响。
· 获取激活文件后，放到本目录（文件名与 activation.filePath 一致），重启即可。
· 激活文件由提供方用激活工具生成：把「激活工具」解压到本目录的 tools\ 下，
  双击 tools\生成激活文件.bat，输入设备标识和有效天数即可，生成的 .lic 保存在本目录。
· 试用天数默认 7 天，配置文件里不需要写 activation.trialDays。
